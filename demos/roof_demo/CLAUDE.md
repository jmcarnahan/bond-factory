# roof_demo

Role: Flutter demo harness for bond_roof_ui and the roof_measure service. Not shipped.

## Key files
- lib/main.dart — entry
- lib/src/demo_page.dart — the single screen: address, method, measure, fixtures, report
- lib/src/service_client.dart — POST /v1/measurements then poll GET (bearer from ROOF_TOKEN define)
- lib/src/labels_es.dart — sample Spanish RoofLabels map (EN/ES switch)
- lib/src/model_panel.dart — inline totals and warnings
- lib/src/tokens.dart — layout tokens and default service URL (http://127.0.0.1:8011)
- assets/fixtures/ — GENERATED by `make sync-fixtures` from ../../fixtures; gitignored except .gitkeep
- tool/sync_fixtures.sh — the generator

## Commands
- Test / analyze: `make test`, `make analyze` (both sync fixtures first)
- Run in Chrome: `make run-web`; release build: `make build-web`
- Service: `make -C ../../services/roof_measure serve`
- Other service URL: `flutter run -d chrome --dart-define=ROOF_SERVICE=http://host:port`; token: `--dart-define=ROOF_TOKEN=...` (dev only)

## Rules
- Never hand-edit assets/fixtures/; edit ../../fixtures and re-sync.
- No popups: the gate applies here too.
