# sdk_demo

Flutter web harness for the bond SDK packages. Never shipped. Seven pages: Home lists the routes, UI is the
`bond_ui` widget gallery, API probes health and errors, Auth signs in and renews a session, Sync uploads rows
with per-row verdicts, Connections runs the fake OAuth round trip, and Tasks manages tasks with reminders and a
calendar mirror. Wiring is shown in `docs/sdk/examples.md`; the browser walk recipe is `docs/test/WEB.md`.
