# Roof Dart packages MIT and roof_measure as a library (2026-11-11)

Context: the apps want to pin the Dart packages `bond_roof` and `bond_roof_ui` without taking on GPL, and to call the
roof pipeline in-process instead of over REST. This record supersedes D10 and the "Licence" section of
`2026-11-10-roof-module-v1.md`, which stays as written. Dated and append-only; later changes get a new file.

## Decisions

- L1 Project default: shared code ships as a library, not a REST service, unless John says otherwise. The roof service
  stays deployable (Dockerfile, hosted) but is no longer the only way in.
- L2 The two Dart packages `packages/bond_roof` and `packages/bond_roof_ui` are MIT, holder John Carnahan
  (Copyright (c) 2026 John Carnahan). Each directory carries its own `LICENSE`, and `NOTICE` lists them as an exception.
- L3 Everything else is GPL-3.0-or-later, `services/roof_measure` included. It links compas_cgal, which wraps CGAL
  Straight_skeleton_2 (GPL per the CGAL documentation). compas_cgal itself declares LGPL-3.
- L4 An app that imports `roof_measure` takes GPL code into that backend. The combined-work caveat applies only if that
  app is conveyed to third parties. This is not legal advice.
- L5 The library facade `roof_measure.measure(...)` returns the unchanged `bond.roof_model/0.2` envelope and raises
  `MeasureError` with the job codes. It takes keys and directories as arguments, not environment variables. It isolates
  the pipeline in a child process. The `service` and `render` extras keep fastapi, uvicorn and matplotlib out of a
  library install.
- L6 No version bump for a licence-only change. Both Dart CHANGELOGs get an `Unreleased` entry.
- L7 A git or Poetry install re-resolves dependencies and ignores `uv.lock`. The consuming app's lock pins them.
- L8 A new warning code `source_unreachable` marks results degraded by a data-source outage. Callers should retry
  later rather than treat such a result as final.

## What stays GPL and why

The roof pipeline needs CGAL's straight skeleton through compas_cgal, and that CGAL component is GPL. Splitting that
dependency out is not planned. The repository root `LICENSE` and every module other than the two Dart packages keep
GPL-3.0-or-later.

## What the Dart packages contain

They parse and draw the roof model JSON. They contain no code from `services/roof_measure`, compas_cgal or CGAL. The
only third-party items are the Mapbox polylabel port in `packages/bond_roof/lib/src/polylabel.dart` (ISC notice in the
header) and the Roboto font in `packages/bond_roof_ui/assets/fonts/` (Apache-2.0, `Roboto_LICENSE.txt`). Direct
dependencies are permissive only: pdf and printing (Apache-2.0), vector_math, lints, test and flutter_lints (BSD).
Package tests read the shared `fixtures/` directory (GPL-3.0-or-later test data generated by the pipeline); it is
not part of the MIT packages.

Not legal advice.
